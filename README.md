# Gioco Viaggio +18
Un gioco interattivo con mappa, personalizzazione del personaggio e sistema di dialogo.

## Caratteristiche
- Mappa interattiva con Leaflet.
- Personalizzazione del genere e dei dettagli del personaggio.
- Dialoghi con personaggi tramite sintesi vocale.
- Gestione del gruppo di viaggio.

## Come eseguire
1. Scarica il file HTML.
2. Apri il file in un browser moderno (es. Chrome, Firefox).
